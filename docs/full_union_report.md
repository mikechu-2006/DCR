## 9. 口径边界

* 绝对 NLL / RMSE 不能和 1k、10k、randommerge 的单集数字互比：总体、ceiling 与
  test 集都不同；要比较模型，必须在同一套 full 划分上重跑。
* 来源 step1 的 split 不复用：pair-random 的随机数按有序对集合展开，并集是对新的
  对集合重新划分（seed 仍为 20260928），所以来源的 train/test 标签在这里没有意义。
* 合并在 play 级：同一 (玩家, 谱面) 的 n_plays、playcount_cur 与 365 天空窗都会按
  并集时间线重算；跨 dump 的同一场 play 只保留一条。
* randommerge 在 README 里的 453,406 对 / 20,388 图是**内容过滤后**的数字；
  本表 step1 未做内容过滤，CM3P 训练前要按内容表取子集。
* star 分桶只是描述性统计（见 docs/low_difficulty_data.md 的勘误），不作分层/加权口径。
