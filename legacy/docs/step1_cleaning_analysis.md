# Step 1 清洗分析：pair-best + ACC 窗口（1k / 10k）

**日期.** 2026-10-20
**实现.** <code>step1/pairbest</code>（[scripts/step1_pairbest.py](../scripts/step1_pairbest.py)）
**数据.** <code>step0_1k</code> / <code>step0_10k</code>；step2 为 <code>bias</code> / <code>mf_dot</code>，
<code>dim=8</code>，<code>F0</code>，<code>epochs=60</code>，<code>seed=0</code>。

**目的.** 记录两套 step1 清洗口径（A/B）的漏斗、step2 指标，追加标签
<code>log(1.001-ACC)</code> 的 C/D 实验，并解释 <code>MAE</code> / <code>Spearman</code> /
<code>pp_p50</code> 的含义。方法细节见 [step1_pairbest.md](step1_pairbest.md)。

**结论先行.** 默认 step1 采用 **A**（pairbest + 0.998 上限 + <code>log(1-ACC)</code>）；
B/C/D 作为消融保留。决定理由与「为什么不用 1.001」见 §4.7。

---

## 1. 两套口径

两套都保留：

- 玩家门槛：step0 记录数 < **20** 的玩家整人剔除；
- 1 年空窗拆玩家（<code>--gap-days 365</code>）；
- 每 <code>(玩家段, 谱面)</code> 只留最高成绩；
- 单次对剔除（<code>--min-plays-per-pair 2</code>）；
- 低 ACC 剔除（<code>--acc-floor 0.90</code>，最高 ACC ≤ 0.90 的整对剔除）；
- 在幸存对上做 pair-random 70/30 划分（seed 20260928）。

两套的唯一差别是**高 ACC 上限**：

| 口径 | 参数 | 保留下来的最高 ACC |
|---|---|---|
| **A：保留 0.998 上限** | <code>--max-best-acc 0.998</code> | (0.90, 0.998] |
| **B：去掉 0.998 上限** | <code>--max-best-acc 1.0</code> | (0.90, 1.0] |

**A → B 不是同一 test 集上的配对比较。** 去掉上限后多了 111,897 / 600,315 个对，
划分单位集合变大，pair-random 会重新分配 test 对；因此下面的差异同时包含「总体变化」
和「test 对变化」。如果要做严格消融，应固定 A 的 test 对，只把高 ACC 对加入训练，
或用同一组留出对给两个模型打分。本文记录的是「改参数后实际跑出来的结果」。

**读法（1k / 10k 同向）：**

- **RMSE / MAE 变大**：去掉 0.998 上限后，最高 ACC 接近 1 的对回来了。因为
  <code>loss = log(1-ACC)</code>，这些对的 loss 会到 −11、−12；平方误差被极端负尾主导。
  1k 的 <code>mf_dot</code> RMSE 从 0.7015 涨到 1.1195（+59.6%），MAE 从 0.5297 涨到
  0.8213；10k 的 RMSE 从 0.6844 涨到 1.0798（+57.8%），MAE 从 0.5504 涨到 0.8237。
  <code>bias</code> 同样：1k +66.4%、10k +66.8%。这正是 0.998 上限原本要压住的东西。
- **Spearman 变大**：标签范围从 (0.90, 0.998] 扩到 (0.90, 1.0]，排序信息更多；模型更
  容易把「谁更好」排对。1k <code>mf_dot</code> 从 0.6749 升到 0.8600，10k 从 0.6966
  升到 0.8350；<code>bias</code> 也从 0.6055 / 0.6723 升到 0.8269 / 0.8038。它**不代表
  绝对预测更准**。
- **pp_p50 变小**：ACC = 1−exp(loss) 在高端被强烈压缩。一个 loss 误差 1.0，在
  loss≈−11 处只对应约 0.003 pp 的 ACC 误差；在 loss≈−2.3 处却对应十几 pp。B 的
  高 ACC 对把 pp 的中位数拉低：1k <code>mf_dot</code> 0.4327→0.1115 pp，10k
  0.5607→0.2935 pp；但这与 loss 空间的 RMSE 变大并不矛盾。
  **pp_p50 不能跨标签范围比较。**

一句话：**0.998 上限是在「保留高 ACC 区域」与「loss 空间 MSE 稳定」之间做取舍。**
去掉它，排序指标更好看、pp 更小，但绝对 loss 误差明显变差。

## 4. 追加实验：标签 log(1.001-ACC)

### 4.1 定义与映射

step0 的标签是 <code>L0 = log(1-ACC)</code>。新实验把它换成

~~~text
L1 = log(0.001 + exp(L0)) = log(1.001 - ACC)
~~~

这是一个**严格单调**变换（ACC 越高，L1 越小），所以每对最高成绩的选行不变；
ACC 过滤也仍按 <code>ACC = 1.001 - exp(L1)</code> 判定：

~~~text
ACC > 0.998   <=>  L1 < log(0.003)  = -5.8091
ACC <= 0.90   <=>  L1 >= log(0.101) = -2.2926
~~~

和旧标签相比，新标签的负尾有界：即使 ACC=1，L1 也只到
<code>log(0.001) = -6.9078</code>，不会像旧标签那样到 −12 甚至 −∞。

| ACC | 旧 L0 = log(1-ACC) | 新 L1 = log(1.001-ACC) |
|---|---|---|
| 0.90 | -2.3026 | -2.2926 |
| 0.99 | -4.6052 | -4.5099 |
| 0.998 | -6.2146 | -5.8091 |
| 0.999996 | -12.4663 | -6.9038 |
| 1.0 | -∞ | -6.9078 |

跑两套：

- **C：保留 0.998 上限 + 新标签**（<code>--label-shift 0.001</code>）。除了标签，清洗和 A 相同；
  1k 的幸存对/划分与 A **完全相同**；10k 有 **8 对**在 ACC=0.90 边界上因浮点舍入不同
  （1,513,738 vs 1,513,746），其余一致。
- **D：去掉 0.998 上限 + 新标签**。除了标签，清洗和 B 相同；幸存对/划分与 B 基本一致
  （同样有边界上的少量差异）。

**比较时看什么：** RMSE / MAE 的单位是各自标签空间，A/B/C/D 之间**不能直接比绝对值**；
Spearman 只看顺序，pp_p50 是 ACC 百分点（shift 在 <code>exp</code> 差里抵消），这两个可以
跨标签比较。下面的“读法”以 pp / Spearman 为主。

### 4.5 读法

- **A → C（只换标签，清洗不变）：** 新标签把高 ACC 段的 loss 压缩了，所以 RMSE / MAE
  在数值上变小（1k <code>mf_dot</code> 0.7015→0.6279），但这只是**标签尺度**的变化；
  Spearman 0.6749→0.6722、pp_p50 0.4327→0.4429 基本不变/略差。也就是说，在同一个
  截断总体 (0.90, 0.998] 上，换标签本身没有让 ACC 级预测更好，只是改变了 MSE 的加权。
- **B → D（去掉上限 + 新标签）：** 旧标签在 ACC→1 时无界，B 的 RMSE 被 −12 的极端样本
  推到 1.12；新标签把尾部钉在 −6.9078，D 的 RMSE 降到 0.6467（1k <code>mf_dot</code>）。
  这是**最直接的效果**：新标签让高 ACC 对可以留在训练/测试里而不炸 MSE。
- **但 D 的 pp_p50 比 B 略差**（1k 0.1115→0.1383；10k 0.2935→0.3349）：旧标签在极高 ACC
  处的 pp 误差被压得极小，B 的 pp_p50 因此非常低；新标签改变了模型在高 ACC 段的加权，
  pp 中位数反而略升。pp_mean 1k 接近（B 0.4296 vs D 0.4263），10k 也接近
  （B 0.7562 vs D 0.7627）。
- **D vs A** 不是同一总体：D 包含 ACC>0.998 的对，A 不包含。D 的 Spearman
  （0.849 / 0.825）和 pp_p50（0.138 / 0.335）都优于 A（0.675 / 0.697、0.433 / 0.561），
  但 RMSE 单位不同，不能直接说 D 的 RMSE 更低。
- **D vs B：** B 的 pp_p50（0.111 / 0.293）和 Spearman（0.860 / 0.835）都略好于 D
  （0.138 / 0.335、0.849 / 0.825）；D 的优势是**标签有界、RMSE 不爆**，不是 ACC 精度
  更高。如果能把 B 的极端 loss 处理掉，B 的 ACC 指标略好；如果不能，D 是更稳的
  loss 回归目标。
- **结论：** 如果目标是保留高 ACC 样本且不让 loss 空间 MSE 爆炸，<code>log(1.001-ACC)</code>
  是有效的；如果目标是和旧实验严格对照，C 给出了同总体下的“只换标签”结果，代价是
  pp/Spearman 基本不变或略差。**但这不是默认口径**：默认仍是 A，理由见 §4.7。

### 4.7 默认口径：A（2026-10-20 决定）

**结论：默认 step1 使用口径 A**，即 <code>step1/pairbest</code> + 最高 ACC 上限 0.998 + 标签
<code>log(1-ACC)</code>；<code>dcr/config.py</code> 的 <code>STEP_DEFAULT_VERSION["step1"]</code> 已设为
<code>pairbest</code>。理由按重要性排序：

1. **A 是唯一同时满足「总体干净 + 标签不爆 + 与已有结果可比」的口径。** A 保留 0.998 上限，
   标签支撑是 <code>[-6.2146, -2.3034]</code>；B 去掉上限后标签到 <code>-12.41</code>，1k <code>mf_dot</code>
   RMSE 被推到 1.1195（A 0.7015），不能作为主评估口径。
2. **B 的 pp_p50 更低，但这不是「更准」。** B 的 1k / 10k <code>mf_dot</code> pp_p50 是
   0.1115 / 0.2935，低于 A 的 0.4327 / 0.5607；但 B 的 RMSE / MAE 是 1.1195 / 0.8213 和
   1.0798 / 0.8237，远差于 A。pp_p50 偏向低/中 ACC 区域，高 ACC 对的 loss 误差在 ACC 空间
   被压缩；用单一 pp 指标选总体会把「更容易的 test 集」误当成「更好的模型」。
3. **C/D 的 <code>1.001</code> 没有依据，且不改善 ACC 指标。** 同总体只换标签（A→C）时，
   pp_p50 0.4327→0.4429（1k）、0.5607→0.5758（10k），Spearman 0.6749→0.6722、
   0.6966→0.6918，基本不变或略差；B→D 的 pp_p50 也从 0.1115→0.1383、0.2935→0.3349。
   换句话说，<code>1.001</code> 的作用是**让高 ACC 样本的 loss 有界**，不是让 ACC 预测更准。
   在没有 ε 敏感性分析、且 0.001 与数据分辨率（1k 最小 <code>1-ACC</code> ≈ 3.85e-6）差 ~260 倍时，
   把它写成默认标签是不合适的。
4. **A 与 [step1_pairbest.md](step1_pairbest.md) §6 的 bias / mf_dot dim=8 结果逐项对应**，
   后续实验可以直接比较；B/C/D 作为消融保留在本文档，不进入默认配置。

**注意：这不表示 A 的 pp_p50 更优。** A 的选择是「评估总体 + 标签支撑 + 可比性」的折中；
如果以后业务上必须覆盖 ACC &gt; 0.998 的对，应该把「总体」和「标签」拆成两个独立决定：
用固定 test 对 + ACC 指标（pp / Spearman）比较，另做 ε 敏感性，而不是用 D 的 test pp 反推默认。

## 5. 指标解释

### 5.1 MAE（mean absolute error）

~~~text
MAE = (1/n) * sum_i | pred_loss_i - true_loss_i |
~~~

- 单位是 **loss**（<code>log(1-ACC)</code>），不是 ACC 百分点。
- 越小越好；对大误差的惩罚是线性的，因此比 RMSE 更不容易被少数极端样本主导。
- 例：1k A 的 <code>mf_dot</code> MAE = 0.529689，表示测试对的平均绝对 loss 误差约
  0.53；B 是 0.821283，平均绝对误差变大。10k A 是 0.550401，B 是 0.823690。
- 不能把 MAE=0.53 直接读成「0.53 pp」；要换算成 ACC 误差得看 pp 指标。

### 5.2 Spearman

~~~text
rho = Pearson( rank(pred_loss), rank(true_loss) )
~~~

- 先分别把预测值和真实值**排序**，再算秩的 Pearson 相关；范围 [−1, 1]。
- **1 = 排序完全一致**，0 = 没有单调关系，负值 = 方向相反。
- 只看顺序，不看绝对误差大小，也不受单调变换影响。
- 标签是 loss（越小 = 越好），所以正相关表示模型把更好的对排在更前面。
- 例：1k A 的 <code>mf_dot</code> Spearman = 0.674891；B = 0.859989。10k A 是 0.696620，
  B 是 0.835008。B 的排序更好，但它的 RMSE/MAE 更差——两个指标回答的是不同问题。

### 5.3 pp_p50 / pp_p90 / pp_mean

~~~text
pp_i = | exp(pred_loss_i) - exp(true_loss_i) | * 100
     = | ACC_pred_i - ACC_true_i | * 100        （百分点）
pp_p50 = median(pp_i)
pp_p90 = 90th percentile(pp_i)
pp_mean = mean(pp_i)
~~~

- **pp 是 ACC 百分点误差**，不是 loss。因为 <code>ACC = 1 - exp(loss)</code>，所以
  <code>exp(loss) = 1-ACC</code>，两条 ACC 的差就是 <code>exp</code> 的差。
- **pp_p50 = 中位数**：一半的测试对，预测 ACC 与真实 ACC 的差不超过这个值。它比均值
  稳健，不会被少数极端对拉走。
- **pp_p90**：90% 的测试对误差不超过此值，用来看尾部。
- **pp_mean**：平均 ACC 百分点误差。
- 例：1k A 的 <code>mf_dot</code> pp_p50 = 0.432723，表示一半的测试对预测 ACC 误差
  ≤ 0.43 pp；pp_p90 = 1.802366，表示 90% 的误差 ≤ 1.80 pp。10k A 是 0.560683 /
  2.234631。
- 例：1k B 的 <code>mf_dot</code> pp_p50 = 0.111459，看起来远好于 A，但 B 的 MAE 更差；
  10k B 是 0.293461。原因是高 ACC 对的 loss 误差在 ACC 空间被压缩；**pp 指标偏向
  低/中 ACC 区域，loss 指标偏向高 ACC 尾部**。

### 5.4 n_scored / coverage

- **n_scored**：真正参与指标计算的 test 行数。
- **coverage = n_scored / n_test**：测试集中能被模型打分的比例。训练词表里没出现过的
  实体（玩家段）或谱面会被排除。
- A 1k：32,308 / 33,139 = 97.49%；B 1k：65,331 / 66,889 = 97.67%。
- A 10k：452,664 / 453,856 = 99.74%；B 10k：633,144 / 634,072 = 99.85%。

### 5.5 为什么 RMSE/MAE 与 pp 会朝相反方向走

<code>ACC = 1 - exp(loss)</code> 是非线性的：

- 在**高 ACC**（loss 很负）处，<code>exp(loss)</code> 很小，loss 的大误差只对应极小的
  ACC 误差 → 对 RMSE/MAE 很大，对 pp 很小；
- 在**中/低 ACC**（loss 接近 0）处，同样的 loss 误差对应大得多的 ACC 误差 → 对 pp 很大，
  对 loss 指标相对温和。

所以「RMSE 高、pp_p50 低」并不矛盾：它们加权的是标签分布的不同区域。

## 6. 注意事项

1. **A → B 的 test 集变了**：多了 111,897 / 600,315 个对，pair-random 重新分配 test 对。
   这不是同一批 test 对上的配对比较；差异包含总体变化和划分变化。
2. **两套都用了标签做过滤**（0.90 下限、0.998 上限），且作用在 test 上，属于
   selection on outcome。严格评估阈值本身，应在过滤前先留出对。
3. **20 条是 step0 记录数**，不是真实游玩次数；空窗也是按记录算的。
4. **0.90 下限只作用于 pair-best 那条**：一个对可以有低于 0.90 的历史 play，只要最高
   一条 > 0.90 就保留。
5. **pp 指标不能跨标签范围比较**：A 与 B 的 pp_p50 差异主要来自高 ACC 对的压缩效应，
   不能读成「B 的 ACC 预测更准」。
6. **与旧 play 级数字不可直接比**：旧 README 的 1k bias 1.5236 / mf_dot 1.4548、
   10k 1.3727 / 1.3327 是未清洗 play 上的 RMSE，总体与标签支撑都不同。
