# 学习率随谱面 / 玩家的异质性（**loss 单位**）

**问题**：`docs/play_order_analysis.md` §1.4 得到 cell 内学习率 ≈ **ΔACC ≈ 0.0134·ln(cum)**。
这个学习率在不同**谱面**之间、不同**玩家**之间差多大？
**前提**：项目训练用的是 **log loss**（`loss = log(1−ACC)`），不是 ACC，所以本文一律以 loss 单位为主口径。

**数据**：`charts_v2_{1k,10k}_v3.parquet` 的 primary cell + `plays_v2_{tag}_v3.parquet`。
**脚本**：`scripts/learning_rate_variance.py`（产物 `data/processed/learning_rate_*`，图 `docs/figs/lr_*`）。

| | 1k | 10k |
|---|---|---|
| primary cells | 141,477 | 1,237,444 |
| 参与估计的 cell（n≥5） | 51,530 | 487,375 |
| 谱面数（≥10 个 cell） | 1,056 | 6,354 |
| 玩家数（≥10 个 cell） | 516 | 5,881 |

---

## 0. 定义

每个 cell 内，用该 cell 的**全部成绩**对 `x = ln(cum)` 做 OLS（`cum = percentile × attempts`，见 play_order_analysis §0）：

```
beta_loss = d(loss) / d ln(cum)   < 0 = 越打越好
beta_acc  = d(ACC)  / d ln(cum)   > 0 = 越打越好
```

两者不是独立的，因为 `d(loss)/d(ACC) = −1/(1−ACC)`：

```
beta_loss ≈ − beta_acc / (1 − ACC)
```

**同一个 ACC 增益，在 ACC 越高的 cell 里换来的 loss 变化越大。** 所以 loss 单位的学习率天然带一个「ACC 水平」的放大因子，这是后面所有解读的关键。

只对 **n ≥ 5** 的 cell 估计斜率（n=5 时 `x` 的跨度已经 = ln 9 ≈ 2.20，设计不退化）。

## 2. 离散度里有多少是「真差异」，多少是估计噪声？

OLS 斜率的理论标准误 `se(beta)` 可以直接算（`se²` 就是该 cell 斜率的抽样方差）。按 cell 大小分层：

| n | cells (10k) | se(beta_loss) 中位 | sd(beta_loss) | 噪声方差占比 |
|---|---|---|---|---|
| 5 | 148,371 | 0.174 | 0.460 | 14% |
| 6–7 | 157,327 | 0.154 | 0.402 | 15% |
| 8–10 | 98,314 | 0.133 | 0.357 | 14% |
| 11–15 | 54,056 | 0.113 | 0.329 | 12% |
| 16–25 | 23,133 | 0.096 | 0.314 | 9% |
| ≥26 | 6,174 | 0.079 | 0.321 | 6% |

**观察**：cell 越大，`sd(beta_loss)` 只是**缓慢**下降（0.460 → 0.321），远慢于纯噪声应有的 `1/√n` 速度。
→ 剩下的离散度是**真实差异**，不是样本量不够。

（注：`se` 的分布是右偏的（中位 0.144，最大 2.64），所以全样本 `E[se²] = 0.067` 明显高于 `median(se)² = 0.021`。原因是 log-linear 模型对**饱和型**学习曲线有系统性失拟，残差里混了失拟成分，`se²` 是噪声的**上界**。下面按 `E[se²]` 算的「噪声占比」也因此是上界，「可靠度」是下界。）

---

## 3. 方差分解：玩家 vs 谱面（核心答案）

把每个 cell 的 `beta_loss` 看成 `player` 与 `chart` 的交叉随机效应 + 残差 + 噪声。
用**同玩家不同谱面**、**同谱面不同玩家**的成对协方差估计 σ²_player / σ²_chart——噪声在跨 cell 协方差里不贡献，所以这两个估计**不受噪声影响**：

```
Var(beta) = σ²_player + σ²_chart + σ²_resid + σ²_noise
```

### 10k

| 分量 | 全部 (487k cells) | n≥8 (182k) | **n≥12 (66k)** |
|---|---|---|---|
| 总方差 | 0.1603 (sd 0.400) | 0.1173 (sd 0.342) | 0.1027 (sd 0.320) |
| **σ²_player** | 0.0315 (**19.7%**) | 0.0332 (28.3%) | 0.0364 (**35.4%**) |
| **σ²_chart** | 0.0112 (**7.0%**) | 0.0106 (9.0%) | 0.0104 (**10.1%**) |
| σ²_resid（交互） | 0.0507 (31.6%) | 0.0365 (31.1%) | 0.0318 (30.9%) |
| σ²_noise | 0.0669 (41.7%) | 0.0370 (31.5%) | 0.0242 (23.5%) |
| 可靠度 1−σ²_noise/σ² | 0.583 | 0.685 | **0.765** |

### 1k

| 分量 | 全部 (52k) | n≥8 (18k) | **n≥12 (5.7k)** |
|---|---|---|---|
| 总方差 | 0.2213 (sd 0.470) | 0.1516 (sd 0.389) | 0.1231 (sd 0.351) |
| **σ²_player** | 0.0293 (13.2%) | 0.0312 (20.6%) | 0.0279 (**22.6%**) |
| **σ²_chart** | 0.0153 (6.9%) | 0.0110 (7.2%) | 0.0112 (**9.1%**) |
| σ²_resid（交互） | 0.0842 (38.1%) | 0.0609 (40.2%) | 0.0535 (43.4%) |
| σ²_noise | 0.0925 (41.8%) | 0.0485 (32.0%) | 0.0306 (24.8%) |
| 可靠度 | 0.582 | 0.680 | 0.752 |

### 怎么读

以 **10k、n≥12**（最可信的一档）为准，**只看可靠方差**（扣掉噪声的 0.0785）：

```
玩家        46.4%     sd ≈ 0.19
谱面        13.2%     sd ≈ 0.10
玩家×谱面交互 40.5%   sd ≈ 0.18
```

**结论**：

1. **谱面之间的差异不大**——σ²_chart 只占总方差的 7–10%，换算成 sd ≈ **0.10**，相对均值 −0.38 约 **26%**。谱面平均学习率的 5%–95% 区间是 **[−0.64, −0.19]（10k）**、**[−0.78, −0.17]（1k）**，即所有谱面**都在学**，只是快慢差 2–3 倍。
2. **玩家之间的差异更大**——σ²_player 是 σ²_chart 的 **3.5 倍**（10k，n≥12）。玩家平均学习率 sd ≈ **0.19**，5%–95% 区间 **[−0.63, −0.05]（10k）**。
3. **最大的一块其实是「玩家×谱面交互」**（约 30–43%），也就是同一个玩家在不同谱面上的学习速度差异——这正是 latent-vector（玩家向量 ⊙ 谱面向量）设计想捕获的东西。这个结果**支持** dot-product 建模方向。
4. 全部 cell 里噪声占 42%，是因为 76% 的 cell 只有 n=3–10；`n≥12` 后可靠度升到 **0.75–0.88**。

## 4. loss 单位带来的「假差异」——必须扣掉

因为 `beta_loss ≈ −beta_acc/(1−ACC)`，一个 ACC 水平不同的 cell 会**自动**得到不同的 loss 斜率，即使它的「真实学习速度」一样。

| 检验 | 10k | 1k |
|---|---|---|
| corr(beta_loss, beta_acc) | **−0.471** | −0.404 |
| `beta_loss` 对 `log(1/(1−mean ACC))` 回归的 R² | **0.0005** | 0.0029 |
| corr(beta_loss, 谱面 star) | **+0.094** | −0.037 |
| corr(beta_acc, 谱面 star) | +0.089 | +0.193 |
| corr(玩家平均 beta_loss, 玩家平均 ACC) | **−0.020** | −0.015 |
| corr(玩家平均 beta_acc, 玩家平均 ACC) | **−0.630** | −0.642 |
| corr(谱面平均 beta_loss, 谱面 star) | **+0.307** | +0.086 |

**读法**：

* **玩家层面，loss 变换刚好抵消了天花板效应**。在 ACC 单位下，高水平玩家（平均 ACC 高）的进步速度明显更慢（corr = **−0.63**，因为他们贴着 100% 上限）；换成 loss 单位后这个相关**几乎归零**（**−0.02**）。也就是说：**loss 空间里，高手和低手的学习速度差不多**——这对用 log loss 训练是个好消息。
* **谱面层面没有完全抵消**。star 越高 → `beta_acc` 越大（难图有更多可学空间，1k: +0.19，10k: +0.09），但 mean ACC 越低 → 放大因子 `1/(1−ACC)` 越小，净效应是 **`beta_loss` 反而随 star 略微变得不那么负**（10k: +0.31）。所以「难图学得慢」在 loss 空间里**主要是单位换算的产物，不是真的学得慢**。
* 不过 `beta_loss` 对 `log(1/(1−meanACC))` 的 R² 只有 **0.0005**：水平因子**单独解释不了 cell 级离散度**。因为 `beta_acc` 本身随水平反向变化（越接近上限，ACC 增益越小），两个因子互相抵消。所以 §3 的分解结果**不是**单位换算造出来的假信号。

### 按难度分组（10k）

| star | cells | beta_loss 均值 | beta_acc 均值 (pp) | cell 平均 ACC | 在进步占比 |
|---|---|---|---|---|---|
| <3 | 10,425 | −0.326 | +0.676 | 0.9833 | 66.8% |
| 3–4 | 39,444 | −0.428 | +0.800 | 0.9802 | 81.4% |
| 4–5 | 117,572 | −0.427 | +0.861 | 0.9774 | 87.2% |
| 5–6 | 156,433 | −0.389 | +0.951 | 0.9715 | 90.3% |
| 6–7 | 105,286 | −0.336 | +1.060 | 0.9650 | 92.3% |
| 7+ | 58,215 | −0.294 | +1.124 | 0.9587 | **94.5%** |

* 在 **ACC 单位**下学习率随难度**单调上升**（0.68 → 1.12 pp）；
* 在 **loss 单位**下方向反过来（−0.33 → −0.29，绝对值变小）；
* 但「在进步的比例」随难度**单调上升**（67% → 94.5%）——**难图的进步更确定**，只是 ACC 增益被压缩后 loss 变化显得小。
* ⚠️ **star < 3 的 1 万个 cell 基本是噪声**（在进步占比只有 49%（1k）/ 67%（10k），mean ACC = 0.983 贴天花板，`beta_loss` 中位 = 0）。这批 cell 的「学习率」没有意义，建模时应按 n 或按水平剔除。

## 5. 谱面元数据能解释多少？

对 `beta_loss` 做回归（10k，n=487,375）：

| 特征 | R² |
|---|---|
| star | 0.0088 |
| star + rate + ln(notes) | 0.0116 |
| \+ cell 平均 ACC | 0.0178 |
| \+ ln(attempts) | **0.0194** |

**几乎全是零**。谱面难度、速率、物量、水平、游玩次数**合起来只能解释 beta_loss 的 2% 方差**。
→ 学习率**不是**由谱面元数据决定的，它主要是 (玩家, 谱面) 交互层面的量。这进一步说明：**不要把学习率做成谱面静态属性**，它应该由 latent-vector 内积产出。

---

## 6. 对建模的直接含义

1. **学习率异质性是真的，不是噪声**：`n≥12` 时可靠度 0.75–0.88，且谱面/玩家均值在 cell 数增加时**不发散**（§2 的 sd 下降慢于 1/√n）。
2. **不要给学习率单独立一个谱面标量**：谱面元数据 R² 只有 2%（§5），σ²_chart 只占 7–10%（§3）。把学习率交给 `player_vec · chart_vec` 内积更合适——**交互项本身就是最大的一块方差**（30–43%）。
3. **loss 单位会系统性地奖励「容易的图」**：同一 ACC 增益在 ACC 高的 cell 里 loss 变化更大（§4）。如果模型直接用 loss 当标签，难度分布不均会带来系统性偏差；建议至少把 **star / mean ACC 作为特征或做分层评估**。
4. **star < 3 的 cell 建议剔除或降权**（§4 末尾）：贴天花板、在进步占比 ~50%，纯噪声。
5. **特征形式**：cell 内用 `ln(cum)`（`ΔACC ≈ 0.0096·ln(cum)` per-cell 均值口径），并把 `n` 或 `n/attempts` 纳入（§2 显示 n 越大越接近真实学习率）。

## 8. 已知局限

* **`se²` 是噪声的上界**：log-linear 模型对饱和曲线有失拟，残差里含失拟成分 → 真实噪声占比 ≤ §3 的值，可靠度 ≥ 表里的值。
* **`beta_loss` 与 ACC 水平纠缠**（§4），任何跨 cell 的比较都应同时看 `beta_acc`。
* **`attempts` 跨速率共享**（play_order_analysis §6），DT/HT cell 的 `cum` 偏大 → 斜率偏平。
* **`n≥5` 门槛**：n=5 的 cell 的 `x` 只有 5 个点、跨度 ln 9，斜率方差大（se 中位 0.174），是「全部 cell」那一列噪声占比高的主因。
